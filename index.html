Does that agentic website actually conform? Paste its address and find out — in plain language, with the exact fixes in order.

Check a site

The check reads only what the site itself publishes: its agent-manifest.json, the agent network definition that file names, its links.json and its discovery files. Nothing is sent anywhere else, and no key is needed for the check itself. A site whose host does not allow cross-origin reads cannot be checked from a browser — the card says so when that happens, because that is itself one of the things the profile requires.

What conformance means

An open agentic website publishes three things: a small JSON file that describes its agent network and what its agents can do, a runtime that runs that network in the visitor's browser, and a page where people and other agents can interact with it. The model that powers the agents is the visitor's choice — the site never pays for the visitor's questions, and no site ever receives another visitor's key.

This checker tests a site against the Worldwide Agentic Web MVP Profile 0.3: the manifest is reachable and well formed, the network definition loads and validates (its front agent exists, every agent is described), the peer link map is published, cross-origin reads are allowed, and discovery metadata is present. It is a conformance check, not a quality prize: a site can conform and still be dull, and a brilliant site that forgets its manifest cannot be found by any other agent at all.
